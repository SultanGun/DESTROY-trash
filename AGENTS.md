# AGENTS.md

## Engine version (IMPORTANT - collaboration constraint)
- This project targets **Godot 4.4.1**.
- Do NOT use Godot APIs/features introduced in 4.5, 4.6, or 4.7 unless explicitly requested.
- GDScript skills and examples found under `.opencode/skills/` are written against a Godot 4.7
  baseline for reference only. Adapt code to 4.4.1-compatible APIs before writing it.
- This project is worked on jointly with a teammate who also uses Godot 4.4.1, so keeping code
  4.4.1-compatible is required to avoid breaking their environment.
- Keep `project.godot` `config/features` at a "4.4" baseline when saving from the editor.
